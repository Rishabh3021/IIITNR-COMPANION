# IIIT-NR Pulse 🚀
### Dr. SPM IIIT Naya Raipur Campus Super-App & Academic Hub

**IIIT-NR Pulse** is an all-in-one, feature-rich web application built specifically for students of Dr. Shyama Prasad Mukherjee International Institute of Information Technology, Naya Raipur (IIIT-NR). It centralizes everything a college student needs into a single responsive interface—eliminating the hassle of navigating multiple platforms.

---

## ✨ Key Features & Modules

1. **Live Campus Command Center & Facility Radar:**
   - Real-time **OPEN / CLOSED** status monitor for **B-Mart**, **Central Library**, **Main & Night Canteen**, **Sports Complex & Gym**, **Student Mess**, and **Health Center**.
   - Live Ongoing Class radar with one-click **"✋ Mark Present"** attendance tracking.
2. **Official Timetable & Faculty Directory:**
   - Built from official Autumn 2026-27 PDFs for **B.Tech DSAI (Room 135)**, **CSE (Room 138)**, and **ECE (Room 122)**.
   - Faculty mapping including Dr. Ramakrishna, Dr. Mithilesh, Prof. Srinivasa, Dr. Lakhindar, Dr. Shubhangi, Dr. Aruna, Dr. Amit, Dr. Darash, and Dr. Khilesh Kumar.
3. **YPT Study Tracker & Pomodoro Focus Hub:**
   - Yeolpumta-style subject-wise play/pause focus timers with daily streak counters and live IIIT-NR study room leaderboards.
   - Built-in Pomodoro timer (25m Focus / 5m Break) that auto-credits study time.
4. **75% Attendance Guard & Cloud History:**
   - Subject-wise attendance counters with safety margins ahead of the December 15 short-attendance deadline.
   - Timestamped cloud attendance logs.
5. **Student Mess Menu & Canteen Bill Splitter:**
   - Official August–Dec 2026 weekly mess menu (including breakfast boiled eggs/oats/sprouts).
   - Complete canteen rate chart (including the legendary **₹10 Hot Gulab Jamun** counter note) and an interactive friend bill splitter.
6. **Naya Raipur BRTS Bus Stand & Shuttle Timings:**
   - AC BRTS bus schedules connecting IIIT-NR Gate/HNLU to Raipur Railway Station via Sector-21 CBD and Telibandha.
7. **Academic Calendar & Raman Hostel Directory:**
   - All 19 academic milestones & 17 official gazette holidays (Sem-I 2026-27).
   - Searchable Raman Hostel room allotment and Batch 2026–30 student directory.

---

## 🛠️ Tech Stack
- **Frontend:** HTML5, Tailwind CSS (via CDN), Vanilla JavaScript (ES6+), FontAwesome Icons, Google Fonts (Inter & JetBrains Mono).
- **Backend / Cloud:** Firebase Authentication (Anonymous & Custom Tokens) & Cloud Firestore for real-time student profile and attendance persistence.
- **Architecture:** Zero-build-step single-file web application (`index.html`) running directly in any modern browser and VS Code Live Server.
